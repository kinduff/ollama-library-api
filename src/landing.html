Ollama Library API 🦙

The missing Ollama library API, completely free. Refreshes every hour, newest first, CORS open, no key.

Try it

curl https://ollama.kinduff.com/api/models

Endpoints

GET /api/modelsAll models, newest first.
?q=llamaSearch name and description.
?capability=toolsFilter by tools, vision, thinking, embedding…
?cloud=trueOnly cloud models (or false for local only).
GET /api/models/:nameOne model, e.g. /api/models/d3.

Spec: openapi.json. For LLMs: llms.txt
